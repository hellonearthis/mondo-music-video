# Music Writer Model Overview

In **Mondo Music Video**, the **music writer model** is the Large Language Model (LLM) responsible for turning a song's detected musical structure into visual shot prompts.

---

## 1. What It Does

- **Inputs**:
  - The composed system prompt and visual direction (style card, mood, thematic concept, or lyrics).
  - Open Actor Protocol (OAP) actor bindings (e.g. `<Picture 1>`, `<Picture 2>`).
  - Musical section grammar (shot timings, cuts, energy level, and camera motion).
- **Execution**:
  - Generates structured visual descriptions and shot bodies adhering strictly to the planned timings and slots.
  - Unlike prose-only generation, the writer fills predetermined slots without modifying the musical timing or cut boundaries.
- **Review Loop**:
  - All prompts generated by the writer are passed to **Laya** for semantic evaluation and safety/style checks before video generation begins.
  - In local production mode, up to two corrective passes can be made based on Laya's feedback.

---

## 2. Supported Writer Models & Setup

Mondo does not bundle proprietary LLM weights. It communicates with any standard **OpenAI-compatible `/v1/chat/completions`** endpoint:

### A. Local LLM (Recommended for offline / free operation)
- **Engines**: `llama-server`, `Ollama`, `LM Studio`, `vLLM`, or `text-generation-webui`.
- **Suggested Models**: Qwen 2.5 (14B/32B/72B), Llama 3.1 / 3.3, Mistral, or similar high-instruction-following models.
- **Default Local Endpoint**: `http://127.0.0.1:8080/v1` (or `http://127.0.0.1:11434/v1` for Ollama).
- **GPU Memory Management**: Mondo can optionally be configured to launch and terminate the local writer process before the video diffusion renderer (e.g. ComfyUI) starts, ensuring full VRAM is available for video generation.

### B. Cloud / Hosted API (Pay-as-you-go)
- **Providers**: OpenAI (`gpt-4o`), OpenRouter, Groq, DeepSeek, etc.
- **Configuration**: Set the provider's `/v1` URL, model name, and API key (`MMV_WRITER_API_KEY`).
- **Cost Protection**: Configurable estimated cost per call; paid calls are never retried automatically without operator consent.

---

## 3. Configuration

You can configure the writer model at any time:

- **Via Web Studio UI**:
  - Open the **Settings** tab at `http://127.0.0.1:8091`.
  - Enter the **Writer service URL**, **Writer model name**, and select **local** or **api**.
- **Via Interactive CLI**:
  ```powershell
  & .\.venv\Scripts\python.exe -m mmv.setup configure
  ```
