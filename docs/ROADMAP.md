# Roadmap

The 0.1.0 development preview implements these workflows. This list also tracks
the verification needed before calling it a broadly supported release.

1. Repository preparation: product scope, permissive application license, clean
   history, and separation from the private studio.
2. Music-video vertical slice: public configuration, song planning, writer,
   rendering and automatic assembly, with one active operation and final output.
3. Actor workflow: reference images, visual records, OAP verification,
   import/export, local signing identity and actor-boundary checks.
4. Creative controls: reviewed styles, style harvesting and credits/idents.
5. Export tools: output browsing/download and optional direct Topaz upscale.
6. Setup: platform launchers, environment checks, backend configuration and
   reviewed opt-in model downloads.
7. Release checks: clean-machine installation, complete sample production,
   cancellation, spending consent, OAP round trip and declared platform support.

Pending release work: real GPU/provider/Topaz production, clean-machine
installation on each target OS, broader browser/accessibility review, a reviewed
model-download catalog and a resolved dependency/license inventory. This preview
uses simple duration/BPM timing and public prompt templates.

No GitHub remote or public release is configured.
