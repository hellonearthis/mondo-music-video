# Public instrument references

The owner supplied these new instrument sheets for distribution with Mondo Music
Video under Apache-2.0, the project's license. Each `instrument.json` records the
clean PNG SHA-256, original source SHA-256, actual dimensions and provenance.
Original exports remain with the owner; only cleaned reference PNGs are bundled.

- `guitar/reference.png`: 1360×2048.
- `keyboards/reference.png`: 1664×2496.
- Drums and bass: awaiting owner-supplied sheets.

Native created resolutions are accepted and preserved without upscaling. Each
sheet provides front/rear/side/top/bottom views and detail sections. Some hardware
counts differ between panels; these are initial visual references, not technical
construction drawings. Generation model provenance is not independently verified.

These are instrument props, not OAP actors. Local imports stay in the private app
data directory and are never collected by package-building globs. Do not copy
other actor/style assets here. See `docs/INSTRUMENTS.md` in the repository for the
performance mode and reference-slot rules.
